# 技能skill创建设计原则

当前编排系统下，新增 主/原子skill 时，为保证系统的稳定性、准确性，必须遵守此设计原则。

**注意：**

- 创建skill时，必须依照当前宿主的创建方式（如：claude code的/skill-creator命令、codex的$skill-creator命令、cursor的/create等Agent）

- 创建完成后，必须在技能注册表中注册。以便编排skill查找技能

- 其他

## 主skill设计

1、主skill必须说明自己技能解决什么问题，为编排skill选取技能时提供依据

2、当存在原子skill时，主skill可以编排所属的原子skill；没有原子skill时，主skill直接执行

3、必须有任务的执行流程、节点约束、完成标准、重试机制，如有失败还需要问题说明及。

## 原子skill

1、仅能被所属唯一主 Skill 调用

2、不可拆分的最小的技能单位，单一职责，只做一件事

3、具备明确执行约束、入参校验、执行成功标准、标准化异常返回

## 严令禁止

1、禁止绕过主 Skill，直接意图触发原子 Skill

2、禁止主 Skill 与原子 Skill 之间使用无结构化自由文本传递关键参数

3、禁止外部主 Skill 跨域调用别人的原子 Skill

4、禁止一个原子 Skill 归属多个主 Skill

5、禁止原子 Skill 内部再调用其他原子

6、禁止出现无所属的原子skill

7、禁止模糊描述，所有执行标准必须可量化、可校验
