### 3.6 执行流程

**FLOW-01 删除 Skill**
- 触发条件：点击某行「删除」
- 主流程步骤：
  1. 调用 deleteSkill(id)，弹出原生确认框，正文「确认删除该 Skill？删除后无法恢复」
  2. 用户确认
  3. 从数组移除该 Skill，重新渲染列表
  4. 弹出提示「已删除」，2000 毫秒后消失
- 分支/异常步骤：确认框取消分支，原型中无描述（见 U-03）
- 结束状态：列表不含被删除的 Skill

**FLOW-02 搜索与分类过滤**
- 触发条件：按搜索框关键字与分类下拉选中值过滤列表
- 主流程步骤：
  1. 关键词转小写
  2. 名称或描述的小写形式包含关键词则保留
  3. 分类选中值非空时，分类须与选中值严格相等，否则排除
  4. 渲染过滤结果，总数更新为过滤后条数
- 分支/异常步骤：过滤结果为 0 条时显示空状态（F-16）
- 结束状态：列表与总数反映过滤结果

**FLOW-03 新建 Skill**
- 触发条件：点击「+ 新建 Skill」
- 主流程步骤：调用 goCreate()，跳转 airun-skills-edit.html（不带参数）
- 分支/异常步骤：无
- 结束状态：进入新建/编辑页

**FLOW-04 进入详情**
- 触发条件：点击某行「详情」，或点击数据行（非操作列）
- 主流程步骤：调用 goDetail(id)，跳转 airun-skills-detail.html?id=<id>
- 分支/异常步骤：无
- 结束状态：进入详情页

**FLOW-05 编辑 Skill**
- 触发条件：点击某行「编辑」
- 主流程步骤：调用 goEdit(id)，跳转 airun-skills-edit.html?id=<id>
- 分支/异常步骤：无
- 结束状态：进入新建/编辑页
