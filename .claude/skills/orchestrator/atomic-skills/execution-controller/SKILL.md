# Execution Controller 原子 Skill

## 1. 核心定位

根据任务文件中的依赖和并行层执行原子 Skill，持续更新任务状态并保存可恢复的执行结果。

## 2. 执行规则

1. 每个 Skill 开始前将状态更新为“执行中”，并记录开始事件。
2. 按并行层和依赖顺序执行，不重复执行已完成的 Skill。
3. 成功后更新为“已完成”，写入执行摘要和核心结果。
4. 核心输出追加到共享上下文：

```markdown
<!-- atomic-skill: skill-name -->
核心输出
<!-- /atomic-skill: skill-name -->
```

5. 失败时记录错误和影响等级，更新为“失败”。
6. 可重试错误按有限次数重试；低影响错误允许独立分支继续；高影响错误暂停任务并保留恢复状态。

## 3. 恢复规则

发现已有 `tasks/current/task_skill.md` 时，先读取状态、依赖、执行结果、错误日志和共享上下文。已完成 Skill 不重复执行，失败或中断的 Skill 从最近可执行节点恢复，不覆盖已有记录。

## 4. 完成标准

- 状态转换和执行日志完整。
- 依赖及并行层执行顺序正确。
- 失败、重试和暂停信息可追溯。
- 共享上下文可供下游 Skill 读取。
- 任务文件可支持中断后恢复。
