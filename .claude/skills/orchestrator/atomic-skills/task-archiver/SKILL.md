# Task Archiver 原子 Skill

## 1. 核心定位

负责 Durable Path 任务生命周期的最后一步：按任务 ID 归档任务状态、更新月度索引，并保留可恢复执行记录。Fast Path 不归档。

## 2. 归档前置条件

执行归档前确认：

1. 任务路径来自当前任务状态，不使用固定路径覆盖其他任务。
2. 当前状态为“已完成”或“失败”。
3. “执行中”“待执行”“待恢复”任务不得归档。
4. 结果校验已完成并记录最终结论。
5. 任务状态包含有效的 `task_id` 和 `route_mode`。

## 3. 路径规则

- `route_mode: fast`：返回 `skipped`，不创建或移动归档文件。
- `route_mode: durable`：移动 `tasks/current/task_skill_{task_id}.md` 至 `tasks/history/YYYY-MM/task_skill_{task_id}.md`。
- 旧的 `tasks/current/task_skill.md` 仅作为兼容读取来源；归档时不得覆盖同名历史文件。

## 4. 归档流程

1. 读取并校验指定任务状态。
2. 确保目标月度目录存在且目标文件不存在，或明确执行幂等校验。
3. 将任务文件移动到对应月度历史目录。
4. 更新或创建当月任务索引。
5. 记录用户意图、最终目标、主 Skill、执行路径、创建时间、完成时间、执行摘要、校验结果和归档时间。
6. 验证本次任务的历史文件和索引，不要求当前目录全局为空。
7. 归档失败时保留原任务文件和最终结果，输出具体原因与人工处理路径。

## 5. 完成标准

- Fast Path 明确返回 `skipped`，不产生归档副作用。
- Durable 任务位于正确的月度历史目录。
- 月度索引包含本次任务记录。
- 任务内容、错误日志、共享上下文、校验结果和最终结果未丢失。
- 归档失败不会覆盖现有状态或删除源文件。
- 归档结果可通过任务 ID 和索引恢复。
