# Task Archiver 原子 Skill

## 1. 核心定位

负责任务生命周期的最后一步：归档当前任务文件，更新月度索引，并保留可恢复的执行记录。

## 2. 归档前置条件

执行归档前确认：

1. 读取 `tasks/current/task_skill.md`。
2. 当前状态为“已完成”或“失败”。
3. “执行中”或“待执行”任务不得归档。
4. 结果校验已完成，并记录最终结论。

## 3. 归档流程

1. 将 `tasks/current/task_skill.md` 移动到 `tasks/history/YYYY-MM/task_skill_{任务ID}.md`。
2. 更新或创建当月任务索引。
3. 记录用户意图、最终目标、主 Skill、创建时间、完成时间、执行摘要、归档时间和可固化文档路径。
4. 验证当前任务目录不再有任务文件，或仅有锁文件。
5. 归档失败时保留原任务文件，输出具体原因和手动处理路径。

## 4. 完成标准

- 任务文件位于正确的月度历史目录。
- 月度索引包含本次任务记录。
- 任务内容、错误日志、共享上下文和最终结果未丢失。
- 归档结果可通过索引恢复。
