# 常见区域模板库

供 `page-layout-designer` 在 `draft_first` 模式下生成草案时使用（见 SKILL.md 2.5）。模板只提供**结构骨架**：组件类型、默认交互类型、默认异步状态类型。业务字段名、列定义、接口、文案、权限、数值一律不预填，生成草案时标记 `[待确认]`，由用户补充。

## 使用规则

1. 仅在 `draft_first` 模式使用；`from_scratch` 模式不使用，除非用户明确说“按建议来”。
2. 按区域职责匹配最接近的模板，可多个模板组合；没有合适模板时按普通草案生成，不强行套用。
3. 由模板生成的对象 `confirm_status` 为 `suggested`，并带 `pattern_id`；用户确认后改为 `confirmed`，`pattern_id` 保留用于追溯。
4. 项目已有公共组件能覆盖模板中的组件时，优先使用项目组件并记录来源。
5. 用户修改的差异项只记录差异，不整体重来。
6. 模板中的“默认状态”只是 `loading`、`empty`、`error` 三类状态的类型，不含文案；文案标记 `[待确认]`。
7. 模板不预填组件 `source`。生成草案时按 SKILL.md 阶段 4 的组件来源判定补全：项目有等价公共组件用 `project_common`，同结构在本页多次出现（如多个表单弹窗、多张带分页的表格）建议 `new_shared`，并写明 `reuse_reason`。

## 模板

### P01 `filter-bar` 筛选区

- 组成：若干筛选控件（输入、下拉、日期等）、查询按钮、重置按钮、可选的展开/收起。
- 默认交互：查询（带筛选值触发目标列表请求）、重置（清空筛选并重新查询）。
- 异步与状态：自身非异步；其目标列表的状态归目标列表。
- 需用户确认：筛选字段及类型、选项来源、单选/多选、默认值、是否展开收起、查询触发方式。

### P02 `data-table` 数据表格区

- 组成：表格、分页，可选工具栏、行操作、批量操作、排序。
- 默认交互：分页切换、排序、行操作、批量操作（有则必须进入交互清单）。
- 异步与状态：表格 `async: true`；`loading`、`empty`、`error` 三类状态。
- 需用户确认：列定义、排序列、分页大小、行操作及权限、批量操作、空状态主操作。

### P03 `form-section` 表单区

- 组成：字段分组、提交按钮、取消或重置按钮。
- 默认交互：字段校验、提交（校验 → 请求 → 反馈）、取消或重置。
- 异步与状态：提交标记 `async: true`；`loading`（提交中）、`error`（提交失败）；`empty` 通常为 `not_applicable`，需写明原因。
- 需用户确认：字段、必填与校验规则、默认值、提交接口、成功后的去向、未保存离开的处理。

### P04 `detail-card` 详情信息卡片

- 组成：标题、键值描述列表，可选操作按钮。
- 默认交互：操作按钮（有则逐个进入交互清单）。
- 异步与状态：`async: true`；`loading`、`empty`、`error`。
- 需用户确认：展示字段、字段格式、操作按钮及权限。

### P05 `metric-cards` 指标统计卡片

- 组成：指标名称、数值、单位，可选趋势或对比。
- 默认交互：可选点击跳转或下钻。
- 异步与状态：`async: true`；`loading`、`empty`、`error`。
- 需用户确认：指标、单位、口径、刷新方式、是否可点击。

### P06 `tabs` 标签页或切换

- 组成：标签项、默认项、各项对应的内容区。
- 默认交互：切换（说明切换后内容与数据策略：重新请求或缓存）。
- 异步与状态：内容区异步属性归各内容区。
- 需用户确认：标签项、默认项、切换后的数据策略、是否可关闭或拖拽。

### P07 `form-dialog` 表单弹窗

- 组成：overlay（弹窗）、标题、表单字段、主按钮、次按钮、关闭入口。
- 默认交互：打开（由触发交互指定）、提交（校验 → 请求 → 反馈）、取消、关闭并处理未保存内容；每个按钮有独立 `interaction_id`。
- 异步与状态：提交与内部数据标记 `async: true`；`loading`、`error`。
- 需用户确认：触发源、标题与说明、字段、宽度与位置、遮罩点击是否关闭、按钮文案与样式、提交接口。

### P08 `confirm-dialog` 确认框

- 组成：overlay（确认框）、标题、说明、确认按钮、取消按钮。
- 默认交互：确认（执行目标操作并反馈）、取消（关闭，不产生副作用）；每个按钮有独立 `interaction_id`。
- 异步与状态：确认动作标记 `async: true`；`loading`、`error`。
- 需用户确认：触发源、确认文案、危险操作的样式、确认后的数据变化和反馈。

### P09 `drawer-detail` 抽屉详情

- 组成：overlay（抽屉）、标题、内容区，可选底部操作按钮、关闭入口。
- 默认交互：打开、关闭，操作按钮（有则逐个具备独立 `interaction_id`）。
- 异步与状态：内容区 `async: true`；`loading`、`empty`、`error`。
- 需用户确认：触发源、宽度与位置、内容字段、按钮及行为。

### P10 `page-header` 页面头部

- 组成：页面标题，可选面包屑、说明、主操作按钮。
- 默认交互：主操作按钮（有则逐个进入交互清单）、面包屑跳转。
- 异步与状态：通常非异步。
- 需用户确认：标题文案来源、面包屑层级、主操作及权限。
