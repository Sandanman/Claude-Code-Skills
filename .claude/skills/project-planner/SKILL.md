# Project Planner 主 Skill v1.0（项目进度规划与每日工作生成器）

> 本 Skill 基于用户提供的任务规划，在指定迭代周期内自动生成项目目标分解、每日工作内容及项目进度追踪，支持多项目分组管理和超期预警，具备历史速度学习能力动态调整估算精度。

## 版本历史

- **v1.0** (2026-06-18): 初始版本，整合韬定律 τ 增强体系，支持动态估算调整、多项目分组、超期预警

---

## 核心设计理念

### 三大核心能力

| 能力 | 说明 |
|------|------|
| **目标驱动** | Goal/KR → 任务 → 每日工作，自顶向下拆解，每步可回溯 |
| **动态精算** | 基于历史速度（实际/预估偏差系数 EWMA）持续修正估算精度 |
| **透明预警** | 进度偏差量化分级（黄/橙/红），阻塞原因显式标注 |

### 估算精度原则

- **偏差系数** = 实际工时 / 预估工时（>1 偏乐观，<1 偏保守）
- 按任务类型累计偏差系数（不同类型精度不同）
- 采用 EWMA（指数加权移动平均），近期数据权重更高
- 无历史数据时默认偏差系数 = 1.0，不做调整
- 每完成一个任务，立即重算偏差系数并更新未完成任务的新预估

---

## 核心能力

- **迭代周期规划**：周/双周/月，支持自定义起止日期，自动排除周末和法定节假日
- **里程碑标记**：与项目截止日期对齐，关键节点可视化
- **目标 → 任务双向拆解**：自顶向下拆解 + 自底向上回填，未完成自动结转
- **每日工作内容生成**：按项目分组，支持优先级浮动排序
- **项目进度追踪**：独立进度条 + 全局汇总，健康度打分
- **超期分级预警**：黄（≤20%）/ 橙（≤50%）/ 红（>50%）
- **跨项目资源冲突检测**：同一时间段多个高优先任务撞车预警
- **历史速度学习**：动态偏差系数 + EWMA + 可信度分级（⚠️ 标记低可信度）
- **多种输出格式**：日报/周报/仪表盘，纯 Markdown，可一键复制

## Task Folding 规则

### 可折叠组

| 折叠组 | 包含技能 | 折叠条件 | 折叠后行为 |
|--------|---------|---------|-----------|
| Group A | task-analysis + estimation-tuning | simple 复杂度且任务 ≤5 | 合并为 analyze-and-tune，一次执行 |
| Group B | project-structuring + task-analysis | moderate 复杂度，无跨项目依赖 | 合并为 structure-and-analyze |
| Group C | estimation-tuning + scheduling | complex 复杂度，EWMA 命中率 ≥80% | 合并为 tune-and-schedule |

### 折叠触发条件

**自动折叠（满足任一即触发）**：
- τ_remaining < 30% 且当前步骤 ≤ 步骤 4
- 连续 2 个步骤的 τ 消耗 < 合并后单步骤的 τ 的 70%

**禁止折叠**：
- iteration-setup（核心初始化步骤）
- scheduling（核心排程步骤）
- progress-tracking（核心追踪步骤）
- 用户明确要求每步独立执行（user_required=True）

## 动态估算精度调整

### 4.1 历史速度学习

```
每次任务完成 → 记录偏差系数 → EWMA 平滑 → 更新参考系数

偏差系数 = 实际工时 / 预估工时
  >1.0：预估偏乐观，下次压低
  <1.0：预估偏保守，下次放宽
  ≈1.0：估算体系可信

按任务类型分组累计（dev/test/design/review/deploy/other）
EWMA 权重：近期任务权重更高（衰减因子 α = 0.7）
```

### 4.2 估算修正公式

```
调整后预估 = 原始预估 × EWMA_偏差系数

EWMA_偏差系数计算：
  EWMA_t = α × ratio_t + (1-α) × EWMA_{t-1}
  其中 α = 0.7（近期权重），EWMA_0 = 1.0（无历史时默认值）
```

### 4.3 可信度分级

| 等级 | 历史样本数 | 标记 | 说明 |
|------|-----------|------|------|
| 高 | ≥5 | 无 | 估算可信 |
| 中 | 3~4 | 无 | 基本可信 |
| 低 | 1~2 | ⚠️ | 建议复核 |
| 无数据 | 0 | ⚠️⚠️ | 无历史参考，需人工确认 |

## 进度追踪与预警

### 超期分级预警

| 等级 | 条件 | 标记 | 建议动作 |
|------|------|------|---------|
| 正常 | 偏差 ≤20% | ✅ | 正常执行 |
| 黄牌 | 20% < 偏差 ≤50% | 🟡 | 关注，评估是否需要资源调整 |
| 橙牌 | 50% < 偏差 ≤100% | 🟠 | 预警，需要采取纠正措施 |
| 红牌 | 偏差 >100% | 🔴 | 严重超期，考虑重新评估计划 |

### 项目健康度打分

```
健康度 = 0.4 × 进度分 + 0.3 × 风险分 + 0.3 × 阻塞分

进度分 = 已完成任务数 / 总任务数（0~1）
风险分 = 1 - 超期任务数 / 总任务数（0~1）
阻塞分 = 1 - 阻塞任务数 / 未完成任务数（0~1）

健康度 ≥ 0.8：优秀 🟢
健康度 0.6~0.8：良好 🟡
健康度 < 0.6：需关注 🔴
```

### 跨项目冲突检测

```
同一工作日，同一优先级（≤2）任务数 > 每日容量时：
  → 标注 [⚠️ 资源冲突：项目A(3h) + 项目B(4h) > 每日容量(6h)]
  → 建议调整优先级或延长迭代周期
```

## 主 Skill 完成标准（v1.0，8项）

1. **τ 预算合规**：总 τ 消耗 ≤ 预算
2. **迭代周期正确**：工作日计算无误，排除周末和节假日
3. **任务完整分配**：所有任务分配到工作日，无遗漏
4. **里程碑对齐**：项目截止日期正确关联里程碑
5. **偏差系数已计算**：EWMA 偏差系数正确，含可信度标注
6. **超期预警已生成**：黄/橙/红分级准确
7. **日报/周报已生成**：输出文件写入 outputs 目录
8. **任务状态已更新**：task_skill.md 状态正确

## τ 效率评分

```
τ_efficiency_score = 完成质量分 / (τ_actual_consumed / τ_budget)

评分标准：
- 优秀（≥ 0.85）：τ 节省且质量高
- 合格（0.6~0.85）：τ 正常消耗
- 不合格（< 0.6）：τ 超支或质量低
```

## 注意事项

- 任务依赖形成环时（循环依赖），立即提示用户拆分
- 每日容量超载时，提示冲突并给出建议调整方案
- 无历史数据时，所有估算默认偏差系数 = 1.0，标注 ⚠️⚠️
- 节假日默认使用中国大陆法定节假日，支持传入自定义节假日
- 输出文件保留时间戳，便于历史追溯
- 支持增量更新：修改任务后仅重算受影响部分
