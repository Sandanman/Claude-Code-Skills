# Daily Report 主 Skill v1.0（桌面月度日报生成器）

> 把某一天的实际工作整理成纯文本日报，按月写入 `~/Desktop/日报/YYYY年MM月.txt`。默认今日，可指定日期；同日重复执行只追加不重复的内容；多个终端可同时读取和写入。

## 版本历史

- **v1.0** (2026-11-18): 初始版本。由 project-planner 的日报输出能力独立而来，新增指定日期整理。

---

## 触发与边界

| 场景 | 处理 |
| --- | --- |
| “输出今日日报”“生成日报”“工作总结” | 本 Skill，日期为今天 |
| “输出 11 月 15 日日报”“补写昨天的日报” | 本 Skill，日期为指定日期 |
| “迭代计划”“每日计划”“进度追踪”“超期预警” | 不属于本 Skill，走 `project-planner` |

本 Skill 只记录“已经做了什么”，不做排程、估算、进度和预警。`project-planner` 的当日排程文件可作为可选参考来源，但不是依赖。

---

## 输入

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `date` | 否 | 目标日期，默认今天。接受 `YYYYMMDD`、`YYYY-MM-DD`、`MM月DD日`（年份取今年）、`今天`/`昨天`/`前天`。仅支持单个日期；多天请分次执行 |
| `items` | 否 | 用户直接给出的条目（项目名 + 内容）。给出时优先使用 |
| `project` | 否 | 条目所属项目名；未给出时按“项目归属”规则判定 |

### 日期校验

- 日期必须是真实存在的日历日期；无法解析时返回 `failed` 并询问，不猜测。
- 晚于今天的日期拒绝写入，返回 `failed`（不为未来写日报）。
- 目标月份文件由**目标日期**决定，与执行当天无关；跨月补写只改动对应月份文件。

---

## 内容来源

按下表确定条目，优先级从上到下，**不得臆造没有依据的工作内容**：

| 优先级 | 来源 | 适用 |
| --- | --- | --- |
| 1 | 用户在请求中直接给出的条目 | 任意日期 |
| 2 | 当前会话中已完成的实际工作 | 仅目标日期为今天 |
| 3 | 当前仓库该日期的提交：`git log --author="$(git config user.name)" --since="D 00:00" --until="D 23:59:59"` | 任意日期 |
| 4 | `docs/lijianxin/tasks/history/YYYY-MM/` 中该日期归档的任务摘要 | 任意日期 |

- 同时有多个来源时合并后统一去重。
- 所有来源都没有可用内容时，不写文件，向用户索取该日工作内容，状态为 `partial`。
- 提交信息、任务摘要需要改写成“做了什么”的一句话，不照搬 hash 或任务 ID。
- 输出摘要中必须列出本次条目及来源，便于用户核对。

## 日报格式

纯文本，按月一个文件：`~/Desktop/日报/YYYY年MM月.txt`。首行为 `YYYY年MM月日报`，空行后每天一个段落，日期标题为 `YYYYMMDD`，**按日期升序排列**。

当日只有一个分组（默认）：

```text
2026年11月日报

20261101

1、A项目 某模块
2、A项目 ***
3、B项目 ***

20261102

1、...
```

当日出现多个分组：

```text
20261118

【A项目】
1、A项目 某模块
2、A项目 ***

【B项目】
1、B项目 ***

【web-admin】
1、排查本地构建报错
```

格式约定：

- 条目固定为 `{序号}、{项目名} {工作内容}`，一行一条，不使用 Markdown 语法；非项目条目省略项目名，写成 `{序号}、{工作内容}`。
- 日期段落之间空一行；日期标题与第一条之间空一行。
- 当日只有一个分组时省略 `【xxx】` 标题；出现第二个分组时，把已有条目补上原分组标题后再追加新分组。
- 日报只记录工作内容，不含偏差、预警和明日计划。

### 分组规则（优先级从高到低）

1. **项目优先**：条目属于某个项目时，分组键为项目名；不同终端写入的同一项目条目合并到同一个 `【项目名】` 组。
2. **非项目内容**：与任何项目无关的杂项，分组键为该终端当前工作目录名（`basename "$PWD"`）。
3. 项目名与目录名相同视为同一分组。

项目归属判定：用户指定的项目名 > 条目内容中明确出现的项目名 > 当前工作目录所在 git 仓库名（开发类工作）。仍无法判断时按非项目内容处理。

## 写入规则

### 1. 路径与创建

- `~/Desktop/日报/` 不存在时创建；月度文件不存在时创建并写入首行 `YYYY年MM月日报`。
- 目标日期段落不存在时，**按日期升序插入到正确位置**（补写历史日期时插在对应日期之间，不追加到文件末尾）。

### 2. 追加去重

- 目标日期段落已存在时，只在该段落内追加本次新增条目，不改动其他日期段落。
- 去重键为“项目名 + 工作内容”，比较前去除序号前缀、首尾及连续空白和中英文标点；当日所有分组共用同一去重范围。
- 重复条目直接跳过；全部重复时不修改文件，报告“无新增”。
- 新增条目追加到对应分组末尾并沿用该组连续序号，不重排已有序号。

### 3. 多终端并发读写

多个终端（Claude Code 会话）共享同一个月度文件。

- **读取**：任一终端可读取指定日期的全部分组；只读不加锁。
- **加锁写入**：用 `mkdir ~/Desktop/日报/.lock` 作原子锁，失败每 0.5 秒重试，最多 10 秒；锁目录存在超过 60 秒视为残留锁，清理后重试；仍拿不到锁则返回 `partial`，不强写。
- **加锁后必须重新读取文件**，基于最新内容去重并生成新内容，写入同目录临时文件后 `mv` 原子替换，最后删除锁目录（用 `trap` 保证异常退出也清理）。
- 只改目标日期段落内的目标分组，不改写其他分组和其他终端已写入的条目。

参考实现（bash，macOS）：

```bash
DIR="$HOME/Desktop/日报"; LOCK="$DIR/.lock"
mkdir -p "$DIR"
n=0
until mkdir "$LOCK" 2>/dev/null; do
  age=$(( $(date +%s) - $(stat -f %m "$LOCK" 2>/dev/null || date +%s) ))
  [ "$age" -gt 60 ] && rmdir "$LOCK" 2>/dev/null
  n=$((n+1)); [ "$n" -ge 20 ] && { echo "获取锁失败"; exit 1; }
  sleep 0.5
done
trap 'rmdir "$LOCK"' EXIT
# 加锁后：重新读取月度文件 → 去重 → 写临时文件 → mv 原子替换
```

## 执行流程

```text
1. 解析日期        → 默认今天；校验合法且不晚于今天
2. 收集内容        → 按“内容来源”优先级取条目，无依据则询问
3. 归属与分组      → 判定项目名 / 工作目录分组键
4. 加锁并读取      → 获取锁，读取目标月份文件（不存在则准备新建）
5. 去重与合并      → 定位或插入日期段落，追加不重复条目，必要时补分组标题
6. 原子写入        → 临时文件 → mv → 释放锁
7. 校验与输出      → 读回校验并输出本次新增、跳过及来源
```

路由：单主 Skill、无依赖、低风险、仅追加写入桌面文件，默认 `fast`（L0 校验）。内容来源不足需要向用户确认、拿不到锁需要重试或恢复时升级为 `durable`。

---

## 状态

- `passed`：日期合法，条目已写入或确认无新增，读回校验通过，锁已释放。
- `partial`：无可用内容待用户补充，或拿不到锁未写入。
- `failed`：日期无法解析或晚于今天，写入失败或读回校验失败。
- `cancelled`：用户取消，不改动文件。

---

## 完成标准

1. 目标日期合法，月份文件路径由目标日期决定。
2. 月度文件首行为 `YYYY年MM月日报`；日期标题 `YYYYMMDD` 升序且不重复。
3. 条目均有依据，且已列出来源；没有依据的内容未写入。
4. 同日条目无重复；重复执行未改写其他日期和其他分组。
5. 分组符合“项目优先、非项目按工作目录”；仅一个分组时为平铺格式。
6. 写入经加锁、重读、临时文件原子替换，`.lock` 已清理。
7. 读回文件校验通过：非空、结构完整、序号连续。
