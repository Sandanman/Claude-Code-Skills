# Version Management

## 职责

仅管理当前 `Claude-Code-Skills` 项目的版本文档：

- 读取 `.claude/skills/README.md` 和 `VERSION.md`。
- 校验 `v.大版本号.小版本.小修改` 格式。
- 默认递增小修改位；合法用户输入优先。
- 根据工作区修改生成不超过 30 字的版本描述。
- 在用户确认后同步更新 `.claude/skills/README.md` 和 `VERSION.md` 的版本号、变更描述和更新时间。
- 更新 `.claude/skills/README.md` 时同步维护结构目录和 `Orchestrator 核心改进详解`，使内容反映当前项目状态。
- 移除 README 中过时的版本对比、历史版本并行使用和旧统计说明，避免继续维护失效基线。

不执行 Git commit、Tag、push、branch、stash 或归档 ZIP。

## 执行规则

1. README 不存在时，以 `v.1.0.0` 作为默认基线并报告。
2. README 与 `VERSION.md` 的版本不一致时，展示差异并请求确认，不静默覆盖。
3. 版本号必须匹配 `^v\.[0-9]+\.[0-9]+\.[0-9]+$`。
4. 将用户输入的版本号与当前最新版本进行比较：
   - 用户输入版本号低于当前最新版本时，必须提示：`当前最新版本为 <current-version>，是否确认使用更低版本号 <input-version>？`，未获得明确确认不得写入。
   - 用户输入版本号与当前最新版本一致时，不新增版本条目，仅更新当前版本的描述信息。
   - 用户输入版本号高于当前最新版本时，按新增版本处理。
5. 总结当前修改并生成不超过 30 字的描述；更新时间使用实际执行日期。
6. 写入前展示当前版本、最终版本、修改描述、更新时间、同步内容、目标文件和已有工作区修改。
7. 用户确认后同步更新 `.claude/skills/README.md` 与 `VERSION.md`，包括版本号、变更描述和更新时间；同时根据当前项目状态更新 README 的结构目录与 `Orchestrator 核心改进详解`。
8. 更新 README 时删除过时的版本对比表、旧版本并行使用说明和仅服务历史基线的统计内容。
9. 更新后校验两个文件的版本号、描述和更新时间一致。

## 版本选择逻辑

- 未提供版本号：默认将当前最新版本的小修改位加 1，并按新增版本处理。
- 提供版本号且高于当前最新版本：按用户输入的版本号新增版本条目。
- 提供版本号且低于当前最新版本：先展示降级提示并请求明确确认；确认后才允许使用该版本号。
- 提供版本号且等于当前最新版本：不新增版本号或版本条目，仅更新当前版本的描述信息。

## 安全边界

不修改 `.claude/settings.local.json`，不生成虚假提交 hash，不创建归档，不执行破坏性 Git 操作。

## 输出

返回 `status: passed | partial | failed | skipped`，并列出版本来源、版本号、描述、更新文件、确认状态和校验结果。
