# Doc Format Conversion

## 职责

在明确支持的源格式和目标格式之间转换文档，可生成目录、应用主题、合并 Markdown，并保留可识别的标题、代码块、表格和链接。转换不负责补造源文档中不存在的业务内容。

## 输入

- `source_paths`：一个或多个源文件。
- `source_format`：`markdown`、`html`、`json`、`openapi_json` 或 `openapi_yaml`。
- `target_format`：`markdown`、`html`、`pdf`、`json` 或用户指定且已确认支持的格式。
- `conversion_config`：主题、目录、代码高亮、资源路径和合并顺序。
- `output_path`：必须由任务指定或预览确认。

## 执行逻辑

1. 检查源文件、格式组合和输出路径，拒绝不支持的组合。
2. 解析源结构，记录无法解析的元素。
3. 选择可用转换器；Pandoc、浏览器渲染器或高亮工具缺失时不静默声称完整转换。
4. 应用主题、目录和资源路径规则。
5. 生成预览，检查已有目标文件后写入。

## 完成标准

1. 源文件可读取，目标格式属于已确认支持范围。
2. 标题层级、正文、代码块、链接和表格在转换后可读取；图片路径处理结果已说明。
3. 输出文件存在、非空、路径与预览一致。
4. 工具缺失、格式降级、资源丢失和无法解析项均已记录。

## 完成后校验

重新读取输出并检查格式结构、编码、链接和代码围栏。PDF 仅在实际生成工具可用并成功写入时报告成功；否则返回 `partial` 或 `failed`。不自动回退到未获确认的目标格式。
