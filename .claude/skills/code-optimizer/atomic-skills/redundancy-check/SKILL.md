# Redundancy Check 原子 Skill

## 概述

在不修改代码的前提下，精确定位文件内和跨文件重复、未使用声明、冗余导入及组件属性冗余，为优化方案提供证据。

## 核心能力

- 检测 Vue SFC 的 template、script、style 和 TypeScript 类型重复
- 检测未使用 export、函数、变量、类、类型、组件 props 和 import
- 识别动态引用并标注不确定性，避免误删
- 按 high、medium、low 分级，生成带路径、行号、证据和修复步骤的报告

## 输入

目标文件或目录，可选语言、框架和忽略规则。

## 输出

共享上下文键：`redundancy_report`。报告包含扫描范围、重复/死代码清单、严重级别、误报风险、修复建议和预估影响；不得把预估值写成实测值。

## 执行逻辑

重复代码检测和未使用代码检测可并行执行，完成后统一汇总和排序。动态导入、反射调用或测试专用代码必须标注“需人工确认”。

## 依赖关系

- 依赖：无
- 并行：与 `quality-and-perf-analysis` 并行
- 被依赖：`pattern-and-benchmark-recognition`

## 完成标准

每个冗余点都有路径、位置、类型、严重级别和修复建议；报告覆盖重复代码、死代码和冗余导入，并包含扫描限制和行动顺序。

## 错误处理

解析失败的文件单独记录并继续；动态引用不确定时不判定为死代码；目标为空时报告原因并停止本阶段。

## 安全边界

只读分析，不删除代码、不自动应用建议，不写入敏感内容。
