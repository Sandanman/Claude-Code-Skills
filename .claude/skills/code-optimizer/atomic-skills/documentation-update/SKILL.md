# Documentation Update 原子 Skill

## 概述

在验证阶段完成后，检查受影响的公共 API、组件、重要函数和配置说明，只更新确实需要同步的文档。

## 核心能力

- 更新组件、函数和公共 API 注释
- 同步 README 使用示例、行为和性能说明
- 更新 API、配置和变更说明
- 检查文档示例与实际代码一致

## 输入

`verification_report`、`applied_changes`、受影响文件和项目文档规范。

## 输出

共享上下文键：`doc_updates`。清单必须包含文档路径、更新内容、依据、状态和验证方式；不存在或无需更新的文档要记录原因，不伪造路径。

## 执行逻辑

1. 根据实际变更识别受影响文档。
2. 阅读现有文档和代码，生成最小同步修改。
3. 检查链接、示例、API 名称和参数是否一致。
4. 输出文档变更清单并移交主 Skill。

## 依赖关系

- 依赖：`optimization-verification`
- 被依赖：无

## 完成标准

公共 API、组件和重要函数的文档已同步，或明确记录无需更新/文件不存在；示例和说明与实际代码一致；报告列出所有文档变更路径。

## 错误处理

文档不存在时记录跳过；格式或链接检查失败时记录问题；验证未通过时不得把优化描述为已完成。

## 安全边界

只修改与已确认优化直接相关的文档，不扩大产品说明范围，不写入密钥、内部环境变量或未经验证的性能承诺。
